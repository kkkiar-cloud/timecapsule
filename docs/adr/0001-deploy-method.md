# ADR-0001. Способ доставки кода на сервер

- Статус: принято
- Дата: 2026-10-11

## Контекст : приложению TimeCapsule нужен способ выкладывать новые версии на один сервер EC2; хочется знать, какая версия работает, и уметь откатываться.

## Решение : сервер сам забирает код из GitHub командой git pull, потом composer install, php bin/init-db.php и reload php-fpm, всё вручную по SSH.

## Рассмотренные альтернативы : scp с компьютера: просто, но неясно, какая версия на сервере, легко забыть файл. Скрипт deploy.sh: меньше ручных ошибок, но нужно писать и поддерживать скрипт.

## Последствия : плюсы (версии в git, откат через git revert, сервер только читает репозиторий) и минусы (пять команд вручную, риск что-то пропустить, на обновление уходит время; ты сама измерила, что поломку исправили за 5 минут).
